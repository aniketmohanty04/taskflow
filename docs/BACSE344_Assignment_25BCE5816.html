5. Cloud Computing Concepts Demonstrated

  • Platform as a Service (PaaS): Render.com abstracts underlying Linux server orchestration, handling process execution, port binding, and runtime health checks.
  • Database as a Service (DBaaS): MongoDB Atlas provides automated failover replica sets in AWS Mumbai, automated patching, TLS encryption in transit, and continuous snapshots.
  • Global Edge Content Delivery (CDN): Vercel caches and serves the optimized React production bundle from 100+ global edge locations.
  • Continuous Integration & Continuous Deployment (CI/CD): Every Git commit pushed to GitHub automatically triggers automated builds and deployments on Vercel and Render.
  • Multi-Tenant Data Isolation: JWT authentication middleware ensures every query is strictly filtered by req.user.id, preventing cross-tenant data access.
